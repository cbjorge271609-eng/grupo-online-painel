Enviar extrato do banco arquivo .OFX — reenviar o mesmo mês não duplica nada

Cada lançamento é identificado pelo código que o próprio banco gera. Se você mandar o mesmo arquivo de novo, ou um período que se sobrepõe, os repetidos são descartados. O número da conta não é guardado — só o apelido que você der.

Conciliação o que está sem categoria não entra no DRE

Trocar a categoria de um lançamento já regrava a despesa dele no DRE. Ignorar serve para o que não é do negócio e para as entradas — o dinheiro que a Shopee repassa não é faturamento novo, o faturamento já vem dos pedidos.
